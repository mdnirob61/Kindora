</h2>

**Kindora** is a community-driven social development platform designed to make volunteering and community participation easier. Users can discover upcoming events, join meaningful activities, and organize their own initiatives to make a difference.

Whether it's cleaning public spaces, planting trees, donating essentials, or helping people in need, Kindora makes it easier to turn small actions into meaningful contributions.

## ✨ Features

| Feature | Description |
|---|---|
| 🌍 **Explore Events** | Discover upcoming community service events created by different organizers. |
| 🔎 **Search & Filter** | Find events easily using the search bar and event category filters. |
| 📋 **Event Details** | Explore event descriptions, locations, dates, and organizer information. |
| 🤝 **Join Events** | Join community activities and become part of positive change. |
| ➕ **Create Events** | Organize your own community service events. |
| 🛠️ **Manage Events** | Update or delete events that you have created. |
| 📅 **Joined Events** | View and manage the events you have joined. |
| 🔐 **Authentication** | Secure login and registration with email/password and Google authentication. |
| 🌙 **Dark Mode** | Switch between light and dark themes. |
| 📱 **Responsive Design** | Enjoy a consistent experience on desktop, tablet, and mobile devices. |
